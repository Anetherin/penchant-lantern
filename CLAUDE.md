# Notes for Claude

## Architecture & Build
- Plain JS split into classic scripts (shared globals, inline `onclick` handlers). No bundler, no modules.
  Script order is defined in `loader.js` (`FILES`); `tools/build.mjs` reads the same list. Add new files there.
- Every top-level name is global across files; avoid name clashes (grep before adding).
- Editable text/numbers live in `data/`; `loader.js` (`DATA_FILES`) fetches them into `window.PL_DATA` before any
  script runs, and `tools/build.mjs` inlines them into `dist/hollowmere-nights.html`. New data set → add to `DATA_FILES` (and `DATA_DIRS` if split). Keep `_readme` keys current.
- Split data sets (`DATA_DIRS` in `loader.js`: `characters`, `guests`, `arcs`, `afterstories`, `flavor`, `firsts`, `goddess`, `traits`) live in folders: `data/<name>/index.json` lists parts, deep-merged in order (objects by key, arrays concatenated; a scalar defined twice fails `tools/build.mjs`). Node tools read data through `tools/data.mjs` (`loadData(name)`, `partFiles`, `allDataFiles`). Run `node tools/fmt-json.mjs` after editing data files programmatically.
- Logic-heavy content (house stories, encounter choices) stays in JS. Random events keep logic in `js/events/random.js` and wording in `data/events.json` via `ET(...)`. Partner arcs (`data/arcs/`) and after-stories (`data/afterstories/`) use a declarative effect schema resolved by `resolveEff()` in `js/stories/partners.js`; bond events (`data/bonds.json`) use `applyBondChoice()` in `js/events/bonds.js`; walk events (`data/walks.json`) use `applyWalkOutcome()` in `js/events/walks.js`.
- Save state version is `S.v = 37`; migrations live in `migrate()` (`js/logic/state.js`). Bump `S.v` when changing save shape.
- `NAMED_LOOK` fields (`name`, `race`, `sub`, `age`, `design`, `body`, `style`, `favColor`) are stripped from saves/exports by `saveReplacer` (`store.set(k, v, rep)`) and refilled from data by `namedLook()` in `ensureWorker`, so data edits reach existing saves. Generic ladies keep theirs in the save.
- No Creator tab (`LIB` templates still feed the candidate pool in `refreshCandidates`).

## Writing & Image Prompts
- Scene text follows `docs/WRITING.md`: second-person narration ("you" = Sam; "Sam" stays in dialogue, UI/logs/reports, and AI/image payloads), direct explicit wording instead of euphemisms, and wording that matches the service played. All characters are adults.
- Image prompts are built programmatically (`js/logic/prompts.js`). Intimate scenes (`isSvcScene`) lead with `scenes.json → people` head-count tags, pose, and service snippet, then `charDesc(w)` (`bodyDesc(w)` merges `design.build` + `body` into one phrase), clothing (`clothText`, `pubicText`), expression, and setting. `design.accessories` + `outfit.accessories` respect `w.accState` (`dressed`/`under`/`always`/`off`); `design.features` stays visible (`featureSkip` excludes non-visual tags).
- Bath scenes (`bath:true` / `towel:true` / `~~bath`) use the bathhouse; only `bath:true` outfits stay on. Swim scenes (`swim:true`) keep `bath:true` outfits on without a towel. `undress` sets invitation dress level. Sam scenes (`samact:`/`duo:`) roll a dress level per moment via `samSceneCloth`. Story moments can define `{comp, setting, sam}` → `dynScene(key, img)` (`js/data/scenes.js`).
- AI text is opt-in per scene (✨ button; `SET.ai.auto` defaults off, except `autoBackstory` for generics). `{outcome}` comes from `aiOutcome()` + `ai-prompts.json → outcomes`; `actSituation()` supplies service context.

## Stats, Effects, Traits & Titles
- Lady stats (`STAT_KEYS`, 8 total: `beauty`, `charm`, `charisma`, `refinement`, `wits`, `stamina`, `strength`, `agility`), `tech` skills, and `acts[id].skill` run `0-1000` (`SKL = 10`, `s100(v)`, `clampK`); data files stay `0-100` and convert at creation (`genWorker`, `makeNamed`). Stat cap is `statCap()` (`ngplus.cap.base + perCycle * (cycle - 1)`), growth curve denominator `growDen() = statCap() + 300`; never hard-code `1000`/`1300`. See `docs/STATS.md` for weights and formulas.
- Stat bonus layer (`js/logic/fx.js`): `w.stats` holds trained base stats; race/sub `mods` (except `lewd`), `fx.stats`, and worn outfit/underwear `stats` add live via `statOf(w, k)` / `statBonus(w, k)`. Every gameplay read must use `statOf(w, k)`.
- `SAM_STATS` (5 total, `0-100`, ceiling `samCap() = statCap() / 10`): `charm`, `business`, `strength`, `wits`, `technique`. Passive bonuses via `samBonus(k, stat)` (`balance.json → sam.bonus`); max energy `samMaxEnergy()`, +1 AP every 5 levels (`apMax()`).
- Effects engine (`js/logic/fx.js`): `fxMul/fxAdd/fxHas/fxSub/fxArr` merge `data/traits/` (`general`, `earnable`, `ngperks`), `data/races.json`, `data/body.json`, `w.unique`, `w.ngPerks`, and active title (`w.titleId`). Vocabulary is in `data/traits/base.json`. Developable traits (`earn`) check weekly via `earnCheck(w)` against `w.counts` (`countUp`).
- Service ids: `ACT_ALIAS` in `config.js` maps old `caress`/`manual`/`oral`/`paizuri` → `kiss`/`manual_give`/`oral_give`/`breast_give`. Two-way services are `_give`/`_get` pairs.
- Trust & Lewdness stay `0-100` internally; UI displays ×10 (`tShow()`, `tDelta()`, `lShow()`). `minorTrust(w)` is the minimum trust floor for time with Sam. Lewdness gains go through `lewdUp(w, n, cap)`.
- Titles (`js/logic/titles.js`, `data/titles.json`): `w.name` never includes an honorific; display with `titled(w)` on cards/sheets/pickers. Active title `w.titleId` grants its `fx` (`syncTitles`). Earned via seed, weekly `titleCheck`, `TITLE_EVENTS`, or story/arc completion (`awardTitles`).

## Houses, Jobs, Clients & Simulation
- Weekly sim is split across `js/logic/services.js` (client selection, quality/expressions, `runService`/`serveAct`, escalations, `pushyCheck`), `js/logic/week.js` (`simHouse`, `updatePrestige`, `endWeek`), and `js/ui/report.js` (`showReport`, `REPV`: `all` / `h:<house>` / `w:<lady>` with `repWhy` & `repGroups`).
- **House metrics:** `h.rep` is **House Popularity** (gains scaled by `repGain` / `repAdd(h, n)`); `h.prestige` (`0-100`, `housePrestige`, `prestigeTier`: Rowdy/Casual/Respectable/Refined/Prestigious) is **House Class/Prestige** (drifts toward structural target + operational shifts; drives client tier mix, skill/amenity/quarters expectations, price tolerance, and company/rich fees); `S.rep` is **Town Renown**.
- **Jobs (13 in `economy.json`):** `rest`, `courtesan` (`must`, room), `madame` (matches clients/bonded attendants, shields mood, raises courtesan slots via `madameScore`, coaches courtesans & gap-0 attendants via `madameCoach`), `promoter` (draw + optional `w.samples` light services that boost popularity and shift prestige vs house class), `attendant` (1 slot per courtesan; cuts courtesan energy, raises sat, covers refused services), `security` (stops pushy clients, screens client tiers/traits by Wits, caps door overflow by Charm/Charisma), `bartender` (needs `bar`; boosts propositions & rowdiness), `dancer` (`must`, needs `stage`), `bath` (`must`, needs `bath`), `teacher` (needs `classroom`; teaches skills/stats/services/`TEACH_SETS` via `classroomTeach`), `maid` (keeps `h.tidy` via diminishing `(100 - tidy)/maidEase`), `chapel` (needs `chapel`; donations + popularity + prestige, angels at full strength, `chapelClassMul` for pilgrims/clerics), `host` (entertains waiting clients, performs light warm-ups `hostFluff`, or finishes `acceptHost` clients).
- **Client flow & crowding:** `economy.json → classes` (14 classes across 4 `TIERS`: commoner/adventurer/merchant/noble), `makeClient` rolls 1–3 traits (`balance.json → clients.traits`), `statPrefScore` feeds draw, satisfaction, and fee. Busy/full houses use queues (`clients.wait`, `clients.crowd`), security door-stopping, host/bar/stage soothing, and walkout penalties.
- **Pushy clients (`pushyCheck`):** talk-down (Wits/Charm) → goddess guard → security → Sam on the spot (`samRescue`) → unhandled (`endNight` cuts escorts by `nightCap` clients or non-escorts by `1/nights` output).
- **Races:** Spirits & androids take no bed (`sleepers(h)`). Spirits can trigger `spiritPossess` and `spiritPairShift`; androids recharge with weekly fees (`SVC.android`, reduced by `charger`) and `androidAdapt`; angels can awaken as `lantern` (`Lantern Angel` sub) at `svc.angel.lanternLewd`: with trust ≥ `lanternTrust` she asks Sam (`evLanternAsk`), otherwise an easygoing personality (lewd multiplier ≥ 1, not Modest) takes it herself and a reserved one holds until she trusts him or passes `lanternOwn`; demons don't sleep (`svc.demon.hunger`), feed on finishing acts (`sigil` blocks rep/prestige drain), support `w.feedOnly`, `w.autoStud`, and `hungerDrive` (`propDrive`).
- **Amenities & Houses:** `amenitySize` 0 = takes no room (Guard Post, Binding Sigil, Garden, Incense Burner with 5 modes `calm`/`aphro`/`focus`/`velvet`/`amber`, Workshop dwarf build discount, Laundry, Drinks menu `h.drinks` 0–3). `decor` 0–3, `classroom` (1 room), `chapel` (1), `tether` (1), `charger` (1), `suite` (1). Fixer-uppers have `h.damaged` rooms repairable via `repairRoom`/`buyUpgrade('repair')`. `demolish(k)` tears down built amenities/rooms above base (`balance.json → demolish`). `houseCost(id)` scales with `debtWeek()` and owned count; `moveHouse()` reorders `S.houses`.
- **Roster & House UI:** `ROSTER_VIEW` filters by type (`ROSTER_TYPES`), job, race, lust, energy, trust, and sort; default order `rosterRank` (house → partners → story → guests → generics). `HOUSE_ALL` shares "All houses" across Houses/Roster; `viewAllHouses()` holds the overview table, property market, and `debtCard()`.

## Sam, Relationships & Spending
- **Sam's home (`js/logic/home.js`):** `S.samHome` (`samHouse()`, one move/week). Recovery scales with bed tier (`samBedTier`, boosted by `suite` and `samUps`). Without `samReach()` (Teleport Circle or Shadow Clone boon), Sam's passive bonuses, watch/books/rounds/classes, and late-night encounters apply only at `samHouse()`. Owner's Suite allows `S.sleepIn` (`sleepInWeek`, `evSleepIn`). `throwFeast()` and `h.autoFeast` (`autoFeasts`) run per house per week.
- **Dates, Demos & Orgies (`js/logic/dates.js`):** `DATES` (including `chat`), two-step `DATE_AFTER` for 🔥 variants (`samSpicy` → `canSam`), `dateSparks` → `dateInvite`, double dates (`DOUBLE_DATES` + threesomes for Devoted lovers), `demoMenu`/`samDemo` (teaches service to house), `orgyMenu`/`samOrgy` (min tier `orgy.minTier`, spends `orgy.lustAfter`).
- **Walks (`js/events/walks.js`, `data/walks.json`):** `samWalk` finds unchosen partners (`walks.json → partnerIntros` tell the same meeting as `goddess/partner-intros.json`; NG++ returns use `partnerMemoryLines`/`partnerMemoryHire`; up to `partnerCycleMax` in cycle 1+, unlimited in NG++), guests once partners are found, prior lovers in NG++, goddess encounters, casual Technique-building encounters (with Technique-gated recruit), and town rest/coin/flavor events.
- **Firsts, Stories & Intros:** `js/events/firsts.js` (`canSam = samStance && actTier <= w.intim`, `firstData` prefers `events.jump`), `js/stories/partners.js` (`ARCS`, intimacy-aware beats via `resolveArcBeat`), `js/stories/houses.js` + `ngplus-houses.js` (`houseGate(w)` caps trust until story finishes; `STORY_JOINS`: castle→seraphine, hollow→ines, pavilion→ilyana, veil→vharra), `js/stories/afterstories.js` (`AFTER_STORIES` epilogues for joiners & residents after house story), `js/stories/intros.js` (dedicated pre-page intros for houses, partners, Shrine, Bound Vessel, and 3-tier NG++ memory `reMet`; partner intros are `data/goddess/partner-intros.json`: `pages` → `greet` + `choices` → Seliora's `goddess` aside).
- **Spending & Wardrobe (`js/logic/spending.js`):** Paid tutoring (`w.tutor` `weak`|`job`, `w.tutorTier`, `tutorWeek`, `tutorAllMenu`, `S.autoTutor`), gifts (`giftMenu`/`buyGift`/`giftAllMenu`, `giftMode`: free after debt), profit cuts & wardrobe autonomy (`w.cut`, `w.purse`, `w.autoDress`, `wardrobeAllMenu`, `S.autoWardrobe`). `S.houseWardrobe`/`S.houseUnder` (`ownsOutfit/ownsUnder`, `giftHouseItem`); `stashCloset`/`restoreCloset` preserve personal clothes across departures. `SET.autoRenew` auto-renews certain contracts.

## Progression, NG+, NG++ & Goddess
- **Debt (`balance.json → debt`):** `nextDue()` uses `debtShares()` (ramped payments, no balloon) from `S.debt.start`; `payOffDebt()` / `payExtra()` trigger `checkEnd()`.
- **New Game+ (`js/logic/ngplus.js`):** Home house always stays; `S.starters` and finished-story houses qualify (`keepable`, toggled on `NGS.keep`). Kept houses keep upgrades/story and carry `improveShare` (1) of `h.spent` plus `keptHouseShare` into debt; `ngNumbers` adds `loverDebt` + `perLover` scaling and new-house debt. Devoted lovers carry over (draw wages, pick one `ngPerk`, optional `ngRomance` reset); kept-house residents/story-joiners return reincarnated; max-trust guests & favorited generics become `S.alumni` (`inviteFriend`). Everyone carried gains a `w.reborn` stack and keeps `carryShare(w)` of gains above base; `S.lives` remembers departed named ladies (`rebirthNamed`). Carried/alumni bonds scale by `ngplus.bonds.keep`. Cycle 2+ unlocks `ngplus: true` houses/partners, `CYCLE_VARS`, and optional `CYCLE_CHALLENGES` (`S.challengePerks`). `ngSeed()` exports a clean replayable NG+ seed.
- **Goddess & NG++ (`js/logic/goddess.js`, `docs/GODDESS.md`):** Seliora's teases run cycles 1–5 (`evGoddess`, `evGoddessDistract`, walks); binding happens on rebirth once a lady exceeds `fullReborn`. Bound Seliora gets her own tab. Once a lady hits `fullReborn` and Seliora is bound/binding, NG+ enters **NG++** at The Lantern Shrine (`shrine`) with a **Bound Vessel**, soft-resetting Sam/houses/lovers while keeping `S.boons`, `S.pasts`, `S.challengePerks`, `S.goddess`, raised caps, `S.vessels`, and `S.lives` / `S.alumni`.
